# Skadefrekvens i bilforsikring

Modellering av skadefrekvens i fransk bilansvarsforsikring med Poisson-GLM i R, på datasettet `freMTPL2freq` (678 013 forsikringer). Målet er å forstå hvilke egenskaper ved fører og kjøretøy som påvirker hvor ofte det meldes skader, slik det gjøres i forsikringsprising.

*Prosjektet er under arbeid.*

## Kjøring

Åpne `insurance-claim-frequency.Rproj` i RStudio og kjør:

```r
renv::restore()
```

Kjør deretter skriptene i `R/` i rekkefølge og render `report/report.qmd`.
